# AINote 浏览器插件 - 测试计划

## 测试环境
- **浏览器**: Chrome 88+ 或 Edge 88+
- **插件**: 加载 `D:\mycode\ainote\public` 目录

## 测试用例

### 1. 自动渲染 .md 文件
**步骤**:
1. 打开 Chrome/Edge，加载插件
2. 访问 `https://raw.githubusercontent.com/openpeng/ainote/main/README.md`
3. 观察页面是否自动渲染为美观的 HTML

**预期结果**:
- 页面应显示渲染后的 Markdown 内容
- 样式应美观（标题、段落、代码块、链接等）
- 右下角应出现浮动按钮（📝）

### 2. 手动渲染（通过 popup）
**步骤**:
1. 打开任意网页（非 .md 文件）
2. 点击插件图标，打开设置面板
3. 点击 **"手动渲染当前页面"** 按钮

**预期结果**:
- 如果页面包含 Markdown 内容，应渲染
- 否则，应显示提示（或无效）

### 3. 恢复原始页面
**步骤**:
1. 在已渲染的页面，点击插件图标
2. 点击 **"恢复原始页面"** 按钮

**预期结果**:
- 页面应恢复为原始内容（纯文本或原始 HTML）

### 4. 设置面板功能
**步骤**:
1. 打开插件设置面板
2. 切换 **"自动渲染 .md 文件"** 开关
3. 选择不同 **"主题"**（亮色/暗色/跟随系统）
4. 拖动 **"字体大小"** 滑块
5. 切换 **"显示行号"** 开关

**预期结果**:
- 所有设置应实时保存（chrome.storage.sync）
- 切换主题后，已渲染页面应即时更新样式
- 调整字体大小后，已渲染页面应即时更新字体大小

### 5. 浮动按钮功能
**步骤**:
1. 在已渲染页面，点击右下角浮动按钮（📝）
2. 观察页面变化

**预期结果**:
- 点击按钮应切换渲染/原始状态
- 按钮文本/图标应相应变化

### 6. Mermaid 图表渲染
**步骤**:
1. 打开包含 Mermaid 图表的 .md 文件（如 `test-mermaid.md`）
2. 观察 Mermaid 图表是否渲染为图形

**预期结果**:
- Mermaid 代码块应渲染为美观的图表（流程图、时序图等）
- 图表应清晰可辨

### 7. KaTeX 公式渲染
**步骤**:
1. 打开包含数学公式的 .md 文件（如 `test-math.md`）
2. 观察公式是否渲染为美观的数学符号

**预期结果**:
- 行内公式（`$...$`）应渲染为行内数学符号
- 块级公式（`$$...$$`）应渲染为居中块级数学符号

### 8. 代码高亮
**步骤**:
1. 打开包含代码块的 .md 文件
2. 观察代码块是否高亮

**预期结果**:
- 代码块应根据语言显示语法高亮
- 颜色应美观、易读

## 已知问题

### 1. CDN 加载失败
**现象**: 页面显示 "AINote 正在渲染..." 但长时间无响应
**原因**: CDN 资源（markdown-it、mermaid、katex）加载失败（网络问题）
**解决**: 检查网络连接，或使用 VPN

### 2. GitHub/GitLab 页面结构变化
**现象**: 无法正确提取 Markdown 内容
**原因**: GitHub/GitLab 更新了页面 DOM 结构
**解决**: 更新 `content.js` 中的选择器（`querySelector`）

### 3. 插件冲突
**现象**: 其他 Markdown 渲染插件冲突
**原因**: 多个插件同时操作页面 DOM
**解决**: 禁用其他类似插件，或调整插件加载顺序

## 调试技巧

### 查看 content script 日志
1. 打开测试页面
2. 按 F12 打开开发者工具
3. 切换到 **"控制台"** 标签
4. 查看 `AINote` 相关日志

### 查看 popup 日志
1. 右键点击插件图标
2. 选择 **"检查弹出窗口"**
3. 在打开的开发者工具中，查看 **"控制台"** 标签

### 查看 background script 日志
1. 打开 `chrome://extensions/`
2. 找到 AINote 插件
3. 点击 **"服务工作进程"**（或 "背景页"）
4. 在打开的开发者工具中，查看 **"控制台"** 标签
