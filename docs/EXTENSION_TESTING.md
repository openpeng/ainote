# AINote Chrome 扩展 — 测试计划

## 测试环境
- **浏览器**：Chrome 88+ 或 Edge 88+
- **扩展**：加载 `public/` 目录

---

## 测试用例

### 1. MD 原始文本渲染
**步骤**：
1. 访问 `https://raw.githubusercontent.com/openpeng/ainote/main/README.md`
2. 观察页面变化
**预期结果**：
- 右下角出现浮动工具栏
- 点击「📝 渲染」后显示格式化 Markdown 页面
- 左侧自动展开目录面板

### 2. 已渲染页面跳过检测
**步骤**：
1. 访问 `https://github.com/openpeng/ainote/blob/main/README.md`
2. 观察页面
**预期结果**：
- 不应出现工具栏（页面已被 GitHub 渲染）
- 内网 GitLab blob 页面同理

### 3. 目录面板
**步骤**：
1. 渲染一个包含多级标题的 MD 文件
2. 观察左侧目录面板
**预期结果**：
- 自动展开，显示 H1/H2/H3 树形嵌套结构
- 点击目录项平滑滚动到对应标题
- 点击 × 可关闭面板

### 4. 编辑器模式
**步骤**：
1. 渲染后点击「✏️ 编辑器」
2. 在左侧编辑区修改文本
3. 观察右侧预览实时更新
4. 再次点击「✏️ 编辑器」退出
**预期结果**：
- 左右分屏，500ms 防抖实时预览
- 退出后恢复渲染页面

### 5. PDF 导出
**步骤**：
1. 渲染后点击「📄 导出 PDF」
2. 浏览器打开打印对话框
**预期结果**：
- 打印预览中工具栏/目录面板不显示
- 内容样式保留完整

### 6. 恢复原始页面
**步骤**：
1. 渲染后点击「🔙 恢复」
**预期结果**：
- 页面恢复为原始文本
- 目录面板自动移除

### 7. Mermaid 图表
**步骤**：
1. 打开包含 ` ```mermaid ` 代码块的 MD 文件
2. 渲染
**预期结果**：
- Mermaid 代码块渲染为 SVG 图表（流程图、时序图等）

### 8. PlantUML 图表
**步骤**：
1. 打开包含 ` ```plantuml ` 代码块的 MD 文件
2. 渲染
**预期结果**：
- PlantUML 代码块渲染为 UML 图（多服务器 fallback）

### 9. Graphviz / D2 / WaveDrom / Nomnoml / Vega
**步骤**：
1. 分别测试各图表类型的代码块
**预期结果**：
- 各自渲染为对应图表格式
- 失败时显示错误提示卡片（含原始代码）

### 10. KaTeX 公式
**步骤**：
1. 打开包含行内 `$...$` 和块级 `$$...$$` 公式的 MD 文件
2. 渲染
**预期结果**：
- 公式正确渲染为数学符号

### 11. 代码高亮
**步骤**：
1. 打开包含多种语言代码块的 MD 文件
2. 渲染
**预期结果**：
- 代码块根据语言高亮着色

### 12. 独立文件格式

| 格式 | 测试 URL 示例 |
|------|-------------|
| `.ipynb` | raw Jupyter Notebook 文件 |
| `.csv` | raw CSV 文件 |
| `.geojson` | raw GeoJSON 文件 |
| `.adoc` | raw AsciiDoc 文件 |
| `.json` | raw JSON 文件 |

**预期结果**：
- 每个格式显示底部渲染工具栏
- 点击渲染后以对应格式展示内容

### 13. 主题切换
**步骤**：
1. 点击扩展图标 → 弹出设置面板
2. 切换主题（Light / Dark）
**预期结果**：
- 已渲染页面即时更新主题样式

### 14. 快捷键

| 快捷键 | 预期 |
|--------|------|
| `Ctrl+Shift+R` | 渲染 / 恢复 |
| `Ctrl+Shift+E` | 切换编辑器模式 |
| `Ctrl+Shift+D` | 导出 PDF |

### 15. 右键菜单
**步骤**：
1. 在原始 MD 文本页右键
**预期结果**：
- 出现 AINote 相关菜单项（渲染、恢复、导出、编辑器）

## 已知问题

| 问题 | 原因 | 解决 |
|------|------|------|
| 大型 Mermaid 图表渲染慢 | mermaid.js 性能限制 | 拆分图表，减小复杂度 |
| PlantUML 大图 URL 超长 | 编码后 URL 超过 8000 字符 | 拆分图表 |
| KaTeX 部分公式不渲染 | LaTeX 语法兼容性 | 使用标准 LaTeX 语法 |
